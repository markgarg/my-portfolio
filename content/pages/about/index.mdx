I am **Rohit Macherla**, a **Lead Developer and Architect** based in London. For more than 20 years, I have designed and delivered resilient, high-throughput software systems — with the last 15+ years focused on large-scale **Salesforce** enterprise architectures.

Currently, I lead engineering initiatives across major streaming platforms (including Peacock, Sky's NOW TV, and SkyShowtime). My work centers on building scalable Salesforce platforms for high-concurrency global events (such as the NFL Super Bowl, the Olympics, and the FIFA World Cup), modernizing CI/CD pipelines, driving enterprise observability, and integrating AI workflows.

### What I Do

* **Enterprise Salesforce Architecture:** Multi-org design, high-volume event processing, custom integrations, and proposition-agnostic platform frameworks. 
* **Engineering:** Enterprise backend solutions using Java, Node.js, Python, and modern web frameworks like React.
* **Observability & Reliability:** Full-stack telemetry using Prometheus, Datadog, and Event Log File alerts.
* **Modern Developer Platforms:** Automated CI/CD with GitHub Actions, API integration tests, Automated UI tests.

### About This Site

This blog is my space for sharing my thoughts and ideas. You will find practical articles on Salesforce, telemetry, monitoring patterns, developer tooling, and systems design.
