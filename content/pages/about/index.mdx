I am **Rohit Macherla**, a **Lead Developer and Architect** based in London. For more than 20 years, I have designed and delivered resilient, high-throughput software systems — with the last 15+ years focused on large-scale **Salesforce** enterprise architectures.

Currently, I lead engineering initiatives across major streaming platforms (including Peacock, Sky's NOW TV, SkyShowtime (Europe), WOW (Germany & Austria), and Showmax (Africa)). My work centers on building scalable Salesforce platforms for high-concurrency global events (such as the NFL Super Bowl, the Olympics, and the FIFA World Cup), modernizing CI/CD pipelines, driving enterprise observability, and integrating AI workflows.

## Key Highlights

* **20+ Years in Software Engineering:** Deep background spanning enterprise Java, Node.js, Python, Scala, and 15+ years of Salesforce architecture and development.
* **Global Streaming Scale:** Lead architect and developer across 5 international streaming propositions, scaling Salesforce orgs to process millions of events during peak global broadcasts.

## What I Do

* **Enterprise Salesforce Architecture:** Multi-org design, high-volume event processing, custom integrations, and proposition-agnostic platform frameworks.
* **Engineering:** Enterprise backend solutions using Java, Node.js, Python, Scala, and modern web frameworks like React.
* **Observability & Reliability:** Full-stack telemetry using Prometheus, Datadog, and Event Log File alerts.
* **Modern Developer Platforms:** Automated CI/CD with GitHub Actions, static code analysis, API integration tests, and automated UI regression suites.
